你的对话，
不离开你的 Mac

Agent Hub 只读取各应用存在本机的文件，服务只监听本机地址，也拒绝来自其他网页的请求。

常见问题现在就开始用

下载 macOS 版
支持哪些应用？

ChatGPT 桌面版里的 Codex、Claude 桌面版 Code 页面的会话、Grok Bot、WorkBuddy，以及 Cursor Agents 窗口里的云端 agent。Claude 的普通聊天记录存在云端，Cursor 编辑器里的本地对话暂不支持，这两类不会显示。

我的对话会被上传吗？

不会。读取和展示都在本机完成，服务只监听 127.0.0.1，也不会修改任何应用的数据。唯一的联网行为来自桌面版的自动更新：它会向 GitHub 检查新版本，不包含你的对话。从源码运行时没有这一项。

为什么 Codex 的会话不会出现在「需要你处理」？

Codex 的本地数据里没有「等你批准操作」这项记录。同样，Codex 没有可靠的已读标记，所以「已看」以你从面板打开的记录为准。

支持 Intel Mac 或 Windows 吗？

安装包目前只支持 Apple Silicon（M 系列）Mac，macOS 13 及以上，暂未提供 Intel Mac 或 Windows 版本。

我的 Mac 没有刘海，灵动岛还能用吗？

可以。没有刘海的 Mac 上，它会显示在菜单栏正中。

应用更新后读不出数据怎么办？

这些应用没有提供公开接口，存储格式变化时某一列可能读不出来，其他部分照常工作。运行 python3 agent_hub.py --check 查看自检结果，再提 Issue 贴上输出。输出里只有应用版本、安装位置和对话数量，不含标题或内容。

能接入其他应用吗？

可以。每个应用就是 agent_hub.py 里的一个读取函数加一项配置，页面会自动显示，步骤见 CONTRIBUTING.md，欢迎提 PR。

收费吗？

不收费。Agent Hub 以 Apache-2.0 协议开源，安装包和源码都在 GitHub 上。
